Folder `levels`
====

All stage and metro line data are stored here.


File Structures
----

* `stations`: Contains folders that storing definition file of stations.
  Folder named from version of the game development stage.
  Stations in `default` folder will always be loaded by game.
* `metro_lines`: Contains folders that storing definition file of metro lines.
  Folder named from version of the game development stage.
  Metro lines in `default` folder will always be loaded by game.
* `stages`: Contains folders that storing definition file of stages.
  Folder named from version of the game development stage.
  Stages in `default` folder will always be loaded by game.
  Folder `prefabs` stores stages that is made in prefabs.
